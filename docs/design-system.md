# Kinetic Clarity Design System

このドキュメントは、Stitchで作成した「Kinetic Clarity」を、はたるくんのUI基準として固定するためのメモです。

今後のWeb版、Mobile版、Figma、Stitch、CodexでのUI作業では、まずこのデザインシステムを優先します。

## 位置づけ

「はたるくん」は、奨学金返済免除という制度の信頼感と、20代から30代の若者が毎日使いやすい親しみやすさの両方が必要です。

Kinetic Clarityでは、行政サービスの堅さを残しすぎず、スタートアップ系アプリのような清潔感、カード中心の情報整理、やわらかい操作感を目指します。

## デザイン原則

- 制度アプリとして信頼できる
- 奨学金、応募、ポイントの状況がすぐ分かる
- 情報量が多くてもカードで整理する
- 緑を中心に、自然、地域、誠実さを表現する
- ポイント獲得や達成状態ではゴールド系で前向きさを出す
- ガラス調や淡い影は使いすぎず、重要な画面に限定する

## 余白とレイアウト

- 基本単位は8px
- モバイル左右余白は16px
- デスクトップ左右余白は40px
- コンテンツ最大幅は1280px
- デスクトップは12カラムを想定
- セクション間の余白は80pxを目安にする

画面はカード中心で構成します。ただし、ページ全体をカードの中に閉じ込めず、カードは「求人」「イベント」「ポイント履歴」などの個別情報に使います。

## 角丸と奥行き

| 対象 | 角丸 |
| --- | ---: |
| 小さな要素 | 4px |
| 通常ボタン、入力欄 | 12px |
| カード | 16px |
| 大きいパネル、モーダル | 24px |
| チップ、バッジ | 9999px |

影は控えめにします。カードは低い影、ホバー中のカードやドロップダウンは少しだけ浮かせます。

## 主要コンポーネント

### ボタン

- Primaryボタンは `#004D40`、文字色は白
- 角丸は12px
- 重要アクションだけに使う
- Secondaryボタンは白背景または薄い緑背景にする

### カード

- 背景は白
- 角丸は16px
- 境界線は `#BFC9C4` を薄く使う
- 奨学金残高、免除見込み額、ポイントなどの重要数値は大きく太字にする

### 入力欄

- 通常時は `#F8F9FA`
- フォーカス時は白背景、Primary色の境界線
- 本人確認や応募フォームでは入力完了状態を分かりやすく出す

### チップ

- 絞り込み、ステータス、職種タグに使う
- Secondary系の色を薄く使う
- 角丸はpill型

### Bottom Navigation

Mobile版の下部ナビゲーションは5項目にします。

| ラベル | 役割 |
| --- | --- |
| ホーム | 残高、免除見込み、応募状況 |
| 求人検索 | 農業、林業、水産業の求人検索 |
| シミュレーション | 免除額、就業期間の見込み |
| ポイント | 地域イベント、残高、交換 |
| マイページ | 本人確認、プロフィール、設定 |

ラベルは1行で表示し、アクティブ状態ではPrimary dark系の背景で分かりやすくします。

## モーション

- hoverやfocusは200msのease-out
- 画面内の新規表示は300msのfade-in
- カードホバーは2px程度だけ浮かせる
- チェックボックスやラジオは軽いspring表現を使ってよい

## 画面別メモ

### ログイン

制度アプリとしての安心感を出すため、余白を広く取り、背景に淡いグラデーションやノイズを入れてもよいです。本人確認やClerk認証の流れは、怖く見えない表現にします。

### ホーム

奨学金残高、年間免除見込み額、保有ポイント、応募中件数、本人確認ステータスを最初に見せます。

### 求人検索

地域、職種、就業期間、家賃補助、研修有無、マッチ度で探せるようにします。カードには給与、補助、研修、免除見込みを入れます。

### ポイント

地域イベント参加、ポイント履歴、商品券交換までの進捗を同じ画面で見せます。ポイント獲得や交換可能状態にはAccent色を使います。
