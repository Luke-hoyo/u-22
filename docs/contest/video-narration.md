## 本編

はじめまして。近畿大学附属広島高等学校東広島校の、チーム未来への挑戦です。  
僕たちが制作した作品は、支援アプリ「はたるくん」です。

この作品は、第四回全国高校生政策甲子園 中国地区大会で提案した政策をもとに制作しました。

まずは、制作に至った背景である政策の概要です。  
僕たちは、一部の大学生が抱えていて、僕たちも抱えるかもしれない奨学金問題に目をつけました。  
あわせて、奨学金問題と組み合わせて解決できるほかの課題がないか考え、第一次産業の担い手不足にも着目しました。  
この2つを同時に解決できる政策として、「奨学金免除型 第一次産業就労プログラム」を考案しました。  
対象者が「はたるくん」を通じて第一次産業の現場で働き、奨学金の返済負担を軽減していく、という仕組みです。

続いて、作品の構成です。  
今回作成した「はたるくん」は、Web とモバイルの2つに対応しています。  
Web には PR サイトがあり、そこからログインして使えます。  
モバイル版は、今後アプリストアからダウンロードできるようになります。いまは Web からも同じ体験を確認できます。

（ログイン画面）  
まず PR サイトからログインします。  
Google、LINE、メールアドレス、ID でのログインが可能です。  
審査用のテストアカウントは、Web・スマホともにパスワードでログインできます。  
メールアドレスでは、認証コードでのログインも使えます。

（若者ダッシュボード）  
ログインできたらダッシュボードに移ります。  
返済免除見込み、奨学金返済残高、地域ポイント、求人検索など、知りたい情報を一目で分かるようにしています。

（求人画面）  
求人画面では、申し込み状況や募集中の求人一覧が表示されます。  
林業や農業など分類で分かれていて、見やすくなっています。  
いまログインしているのは対象者向け画面で、事業者向け画面もあります。

（事業者画面）  
事業者画面では、募集の作成や参加者の詳細確認などができます。  
事業者向けアカウントは、申請をして認証コードを入力することで作成できます。

（運営画面）  
運営画面もあります。  
募集の管理と審査、参加者の確認、地域イベントの作成が可能です。

（技術）  
基本機能の紹介のあと、技術仕様です。  
Web は TypeScript、モバイルは Flutter を使っています。  
認証は Clerk、データは Appwrite、業務 API は Next.js でまとめています。  
秘密情報はサーバー側に置き、Web とモバイルが同じ API を使う構成です。

（締め）  
政策で考えた仕組みを、実際に動くアプリとして形にしました。  
本番 URL は hatarukun.jp です。ご視聴ありがとうございました。
